Version history

Versions

What each version added, fixed and left open, with a link to its release. Newest first.

Everyone playing together must be on exactly the same version. To update, open the launcher and press Enter (see the user guide); older versions can be installed again from the menu.

v0.3.1

2026-11-04Latest

Fixes from the first playtest: smooth movement for players who joined a game, pick-up only in real range and never through walls, and walls that no longer turn transparent beside you.

What's new
  • Nothing new to play: this build fixes what the first playtest found.
Fixed
  • Choppy movement on joined clients. The character, the carried item and the hint stepped along with the network ticks. They are now drawn smoothly between ticks.
  • The prompt appeared out of range. The window could show up when the server would still refuse. It now shows only inside the real reach (2 metres), and the server accepts a little beyond it so a visible prompt always works.
  • Pick-up through walls. Items behind a wall could be picked up, and a dropped item could land on the far side. Pick-up, delivery and drops now respect walls.
  • Walls turned transparent when you stood next to them. Only walls clearly between the camera and you are cut away now.
Under the hood

Interaction and IsoCamera 0.1.1. Automatic tests: 147 unit tests and 18 play-mode tests, including new checks for walls between player and item and for which walls the camera hides.

Known limits

Not yet confirmed by another player: please retest the five findings. Why a press at an item next to a wall sometimes did nothing for one player is not explained yet.

v0.3.0

2026-11-03Latest

The first playable route: Courier Route. Collect three items, carry them past hazards, hand them in together, with menus that work on a controller. This is the Stage 1 playtest build.

What's new
  • Courier Route: a route with a start pad, a pickup room, a hazard field and a goal; the objective is to hand in three items together.
  • Items: pick up, carry one at a time, drop or deliver, with a pulsing target and a hint ([E] / [A]); held and dropped items go in front of the way you face.
  • Facing: units turn toward the way they move (a dark nose shows it).
  • Health and hazards: the red strips hurt; at zero you are down, drop what you carry and come back at the latest checkpoint after three seconds.
  • Shared objective, timer and results screen; restart the run without leaving the session.
  • New camera that glides after the player and cuts away walls in the way.
  • New menus for mouse and controller (main menu, join, pause, results), a HUD, and a status bar at the bottom right that never shows old information.
Fixed
  • The connection status no longer stays on screen. After leaving a session, Disconnected stayed at the top even when you started or joined another one. It now lives in a status bar at the bottom right, shows only the current session and disappears by itself.
Under the hood

Units 3.1.0, plus new libraries for the camera, interaction, objectives and the interface (not yet published separately). Automatic tests: 135 unit tests and 18 play-mode tests, including three runs in a row, a player joining mid-run and a virtual controller driving the menus.

Known limits

This is a test build: the route has not been played by anyone but its developer. The damage rate, the pick-up range and the camera are first guesses. Typing an address needs a keyboard; the Steam Deck menus and the Windows launcher need your feedback.

v0.2.3

2026-11-03Latest

The Windows launcher: one command installs and updates the game, and a Start menu entry starts it. The game itself did not change.

What's new
  • Windows installer and launcher. Paste one line into PowerShell (or double-click UnknownAdventure-installer.cmd) and the game installs, a Start menu entry named Unknown Adventure appears, and every start checks for a new version first. It works offline, keeps the previous version for going back, and checks every download for size and hash, like the Mac and Steam Deck launchers.
  • The zip for Windows is still published.
Fixed

No gameplay changes in this version.

Under the hood

The installer is a PowerShell script with the same manifest, checks, rollback and menu as the Mac and Linux one. The project now includes the DI container and VContainer (with an injector for networked objects), a test environment (31 unit tests and 9 play-mode tests, run with Tools/test.sh), and the reactive libraries moved from UniRx to R3. None of this changes how the game plays.

Known limits

The Windows launcher and the Windows build have not been run on a Windows PC yet, and the launcher is untested on many setups. A session hosted from a Steam Deck is untested.

v0.2.2

2026-11-03Latest

Interface polish and a fix for the shared ball. The connection panel can be hidden, the controls are always visible, and your last three hosts are remembered.

What's new
  • The state label is now a button that hides or shows the connection panel (Solo, Host, Server, Join, the address list).
  • A Server entry starts a session with no player of its own.
  • Recent hosts: the last three hosts you joined are listed under the address field. Click one to fill the field (you still press Join); x deletes an entry. They are saved on your device.
  • The controls and the state of the ball and the pulse are shown in a box at the bottom left, always.
Fixed
  • Dropped ball. After a drop, players saw the ball in different places and at different heights: the player who held it saw it underneath their own character (hidden behind it), everyone else saw a gold ball hanging at head height. The ball's resting place is now shared state, so everyone sees it on the ground at the same spot, a step in front of whoever dropped it, also for players who join later.
Under the hood

Net library 0.4.0 (the recent-hosts list). The ball's resting position is synchronised state. 53 interaction checks (new: every client draws the held and the dropped ball where the server has it) and 36 helper checks pass.

Known limits

The Windows build has not been run on a Windows PC yet. A session hosted from a Steam Deck is untested. The pulse countdown uses your system's decimal separator.

v0.2.1

2026-11-03Latest

Hosts can now see which addresses friends should use.

What's new
  • When you host, the game lists your addresses with a Copy button each, labelled by kind: VPN / virtual LAN, local network, virtual machine, public.
  • A Show my public address button asks an outside service (api.ipify.org) only when pressed, and says what it can and cannot do.
Fixed

No gameplay fixes in this version.

Under the hood

Net 0.3.0: address listing and on-demand public lookup. 21 classification checks (private ranges and their edges, VPN and virtual-machine interface names, loopback, link-local, IPv6 excluded).

Known limits

A public address only works if your router forwards UDP port 7770 to your computer; behind a VPN or proxy it shows that service's address. Address labels for Steam Deck and Windows adapters are untested.

v0.2.0

2026-11-03Latest

The first gameplay: a shared ball and an ability with a cooldown.

What's new
  • A shared gold ball: pick it up or drop it with E / gamepad A, one holder at a time, within 2 metres. If the holder leaves, it is released.
  • A pulse ability on Q / left shoulder with a one-second cooldown; other players see it.
  • A dedicated server mode (the -server command-line switch).
  • Control hints on screen.
Fixed

No user-facing fixes. One problem was found after release and fixed in v0.2.2: the dropped ball was drawn at different places for different players.

Under the hood

Net 0.2.0 (dedicated server). Tests: three clients grab the ball in the same frame, 15 rounds including 100 ms latency with 5% packet loss, exactly one winner every time; the cooldown; a complete session reset; a headless server with two clients as separate processes.

Known limits

Everyone in a session must be on the same version. The dropped-ball problem above.

v0.1.0

2026-11-03Latest

The first test build: a networking sandbox for Mac, Linux (Steam Deck) and Windows.

What's new
  • Solo, Host, Join by address and Disconnect, with a clear message when versions differ.
  • Walk around a small arena with keyboard and mouse or a gamepad; your own movement feels instant even online.
  • An installer for Mac and Linux with a launcher, updates, rollback and a Steam Deck Gaming Mode option; Windows is a zip. (The launcher and the Gaming Mode option were added to the release afterwards by replacing the installer files.)
Fixed

Nothing to list: this is the first version.

Under the hood

Unity 6000.5, FishNet over Tugboat (UDP 7770), Net 0.1.0 (host, join, version check), Input System 2.0.0 (keyboard, mouse and gamepad as device-independent intents).

Known limits

At release the Linux build had not been run on real hardware; it was later confirmed on a Steam Deck. The Windows build is still untested on a Windows PC.
