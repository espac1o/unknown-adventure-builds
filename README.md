# Unknown Adventure builds

Public test builds of Unknown Adventure. The game source is private; this repository only hosts releases.

## Install

**macOS (Apple Silicon) and Linux / Steam Deck** (desktop mode): open Terminal and run

```bash
curl -fsSL https://github.com/espac1o/unknown-adventure-builds/releases/latest/download/install.sh | bash
```

Press Enter at the menu to install the newest version and start the game. Run the same command later to update.

**macOS, double-click:** download `UnknownAdventure-installer-macos.zip` from the latest release, unzip it and open `UnknownAdventure.command`. The first time, macOS asks for confirmation (right-click, Open).

**Windows:** download `UnknownAdventure-<version>-windows.zip` from the latest release, unzip it and run `UnknownAdventure.exe`.

All players in one session must be on exactly the same version.
