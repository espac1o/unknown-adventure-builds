The game in a nutshell

Unknown Adventure is a cooperative isometric action RPG for one to four players, built one small, complete, playable step at a time. You are looking at Stage 0: a multiplayer sandbox that proves the foundations (connecting, moving, sharing objects, updating) before any RPG systems are built.

  • One player hosts; everyone else joins by address. Playing alone uses the very same rules.
  • Keyboard and mouse or a gamepad, from the first build.
  • Runs on Mac (Apple Silicon), Steam Deck and Linux, and Windows.
  • Test builds arrive as releases; each one is checked automatically before it is published.

Where the project is

The game grows in stages. Each one ends in something you can play and give feedback on, and asks one main question.

#What you can playMain question
0Cross-platform multiplayer sandboxCan the chosen technology support the intended experience?Now
1Courier-style exploration challengeIs moving and interacting enjoyable and readable?Next
2Small cooperative defence encounterIs the basic fight worth replaying?Later
3Three-room micro-dungeonDo equipment and abilities create meaningful choices?Later
4One polished, representative adventureDoes the complete experience work as a small RPG?Later
5Connected expeditions with lasting progressDoes progression keep players interested beyond one session?Later
6Steam test builds and friend sessionsCan players find, join and play reliably?Later
7Release candidateIs the game coherent, stable and supportable?Later

Stage 0 today: hosting, joining and a dedicated server; movement that feels instant online; a shared ball and an ability with a cooldown; an installer with updates, rollback and a Steam Deck mode; automated checks on all of it. Still to come in this stage: a proper automated test setup and a cleanup of the shared code.

Parts of the game

    The last three hosts you joined, two clicks away.
  • Host addresses v0.2.1

    Instant, camera-relative movement that stays in sync.
  • Controls and devices v0.1.0
    Keyboard, mouse and gamepad; hints always on screen.
  • The shared ball v0.2.0
    Grab it, carry it, drop it; exactly one holder.
  • The pulse v0.2.0
    An ability whose cooldown the server keeps.
  • Joining late and starting over v0.1.0
    Join a running game; end it and nothing is left behind.
  • Updates and versions v0.1.0
    Stay current, go back, and know who can play together.
